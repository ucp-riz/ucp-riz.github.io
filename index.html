Ongoing

Selected Projects

Applied AI, forecasting, and data engineering

Project 01

ATTENDANCE SYSTEM

Developed an AI-based attendance system for automated personnel attendance tracking. DeepFace facilitates face recognition, with recognized faces triggering payload uploads to an S3 bucket and a Lambda function storing the data in DynamoDB.

Project 02

DEMAND FORECASTING

Built a demand forecasting solution for a garment store. Ten distinct models were trained using Darts for a univariate problem, with RMSE used for performance evaluation.

Project 03

LOUD FORECASTING

Built XGBoost, LSTM, and Transformer models for short-term load forecasting, with Bayesian Optimization for hyperparameter tuning and multi-metric performance evaluation.

Project 04

SILVER TREE BRANDS

Used Google Big Query to fetch data, performed transformations with guidance from KNIME Legacy workflows, connected Dataform, and wrote SQLX scripts to save transformed results to BigQuery datasets.
